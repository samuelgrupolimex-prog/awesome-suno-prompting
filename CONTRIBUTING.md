# Contributing

## What belongs here

Tools, guides, libraries and communities that help someone write a Suno prompt the model actually follows.

## What does not

- Affiliate or referral links.
- Paid prompt packs with no free way to judge the quality first.
- Dead links, abandoned projects, and sites that have not changed in a year.
- Anything whose only claim is being new.

## How to submit

One entry per pull request. In the description, include:

1. The link.
2. One sentence on what it does, written the way you would tell a friend.
3. Whether it is free to try, and whether it needs an account.
4. **Whether you built it.** Self-submissions are fine. Undisclosed self-submissions get closed.

Keep the table columns filled in. If a tool does not state something publicly, write `Not stated` rather than guessing.

## Corrections

Facts here were checked on a specific date and this niche moves fast. If a price, limit or feature is wrong, open an issue with the current page and it gets fixed. Corrections about competing tools are especially welcome, since the maintainer has an obvious blind spot there.
